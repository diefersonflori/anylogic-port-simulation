# Port Operations Simulation in AnyLogic

This repository contains an AnyLogic simulation model developed to study port operations and evaluate operational scenarios.

The model was built using discrete-event and agent-based simulation concepts and was used to represent port logistics, operational flows, and container-related processes under different planning scenarios.

## Project objective

The main objective of the model is to support capacity and operational analysis of a port system by allowing different scenarios to be tested in a simulation environment.

The repository includes model versions associated with a 2030 planning scenario and supporting datasets used by the simulation.

## Model

The simulation was developed in AnyLogic and includes:

- port operational processes;
- logistics flows;
- container-related operations;
- scenario-based analysis;
- input data integration;
- graphical and 3D elements for model visualization.

## Repository contents

The repository contains different development versions of the AnyLogic model, including:

- AnyLogic `.alp` model files;
- supporting databases;
- input spreadsheets;
- 3D resources;
- model assets and graphical elements.

Some folders represent intermediate development versions of the simulation.

## Technologies

- AnyLogic
- Discrete-event simulation
- Agent-based modeling
- Logistics simulation
- Capacity analysis
- Scenario analysis
- Microsoft Excel

## Application

This project is an example of using simulation to support logistics and infrastructure planning.

It complements my work in mathematical optimization by providing a simulation-based approach for systems where operational interactions, congestion, resource utilization, and variability need to be explicitly represented.
